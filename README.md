# شينز: دليل طيور السعودية

موقع مرجعي عربي لطيور المملكة العربية السعودية: الأسماء العربية والدارجة والإنجليزية والعلمية، الصور، مواسم الوجود شهراً بشهر، الأصوات، آخر المشاهدات، وطقس المقناص.

- البيانات تتحدث تلقائياً عبر GitHub Actions: بيانات الطيور كل أسبوع، والمشاهدات كل 3 ساعات.
- الأسماء الدارجة وطيور المقناص في `data/local-names.json`، وتقدر تعدّلها مباشرة من GitHub.
- المفاتيح (`EBIRD_API_KEY` و`XENO_CANTO_API_KEY`) محفوظة في أسرار المستودع.

المصادر: GBIF، iNaturalist، eBird (مختبر كورنيل)، xeno-canto، ويكي بيانات وويكيبيديا، Open-Meteo.
